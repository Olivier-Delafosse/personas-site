# personas-site

Editorial AI personas studio site for `personas.coreprose.com`.

Hosts:
- Landing page with overview of the editava persona collection
- Individual persona pages (Ada, Marek, Jules, Sven)
- Editorial blog (`/blog`) — bi-monthly posts on persona design, editorial AI, knowledge grounding

## Stack

- **Nuxt 3** (Vue 3 + Vite)
- **Tailwind CSS** for styling
- **Coolify** for deployment via this repo

## Status

🚧 Scaffolding in progress. Initial commit with structure + plan. Full skeleton + content to follow.
